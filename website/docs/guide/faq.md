# FAQ

## Does ApexSU support my device?

ApexSU supports only supported Android GKI devices. If your kernel version does not include `android`, the device is treated as non-GKI and unsupported.

## Can I install ApexSU on non-GKI devices?

No. Installation is blocked on non-GKI devices.

## Is Local LKM a workaround for non-GKI devices?

No. Local LKM is only for supported GKI devices.

## What should I prepare before installation?

Use a boot image matching your exact firmware/build and back up important data.
