<div class="apex-warning">
  <h2>Dukungan hanya GKI</h2>
  <p>Perangkat non-GKI tidak didukung. ApexSU tidak dapat dipasang pada perangkat non-GKI, dan LKM lokal bukan jalan pintas untuk membuat perangkat non-GKI menjadi kompatibel.</p>
</div>

  <h2>Peringatan keamanan</h2>
  <p>Modifikasi boot image dapat menyebabkan bootloop. Selalu gunakan boot.img yang cocok dengan firmware/build yang sama persis dan lakukan backup data penting sebelum instalasi.</p>
