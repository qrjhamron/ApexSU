# Panduan build

Halaman ini membahas build ApexSU untuk alur Android GKI yang didukung.

- ApexSU hanya mendukung Perangkat GKI yang didukung.
- Perangkat non-GKI tidak didukung dan instalasi diblokir.

Referensi:

- Build kernel Android: https://source.android.com/docs/setup/build/building-kernels
- Repo ApexSU: https://github.com/qrjhamron/ApexSU
