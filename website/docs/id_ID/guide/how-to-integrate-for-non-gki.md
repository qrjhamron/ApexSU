# Kebijakan dukungan GKI

Perangkat non-GKI tidak didukung.

- Instalasi diblokir pada semua perangkat non-GKI.
- Tidak ada jalan pintas LKM lokal untuk perangkat non-GKI.
- Repository LKM dan LKM lokal hanya untuk Perangkat GKI yang didukung.

Perangkat non-GKI tidak didukung. ApexSU tidak dapat dipasang pada perangkat non-GKI, dan LKM lokal bukan jalan pintas untuk membuat perangkat non-GKI menjadi kompatibel.

Istilah penting:

- Perangkat GKI: didukung.
- Perangkat non-GKI: tidak didukung.
- instalasi diblokir pada perangkat non-GKI.
- LKM lokal hanya untuk perangkat GKI yang didukung.
