# FAQ

## Quais dispositivos o ApexSU suporta?

O ApexSU suporta apenas dispositivos Android GKI compatíveis. Se o kernel não contém `android`, o dispositivo é non-GKI e não suportado.

## Posso instalar em non-GKI?

Não. A instalação é bloqueada em non-GKI.

## Local LKM funciona como bypass para non-GKI?

Não. Local LKM é apenas para dispositivos GKI suportados.
