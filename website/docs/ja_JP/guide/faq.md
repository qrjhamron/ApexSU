# FAQ

## ApexSU はどのデバイスをサポートしますか？

ApexSU はサポート対象の Android GKI デバイスのみ対応します。カーネルに `android` が含まれない場合は非対応です。

## 非 GKI デバイスにインストールできますか？

できません。非 GKI ではインストールはブロックされます。

## Local LKM は非 GKI の回避策ですか？

いいえ。Local LKM はサポート対象 GKI デバイス専用です。
