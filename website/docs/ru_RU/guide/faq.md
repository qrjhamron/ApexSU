# FAQ

## Какие устройства поддерживает ApexSU?

ApexSU поддерживает только поддерживаемые Android GKI-устройства. Если в версии ядра нет `android`, устройство считается non-GKI и не поддерживается.

## Можно ли установить ApexSU на non-GKI?

Нет. На non-GKI установка блокируется.

## Local LKM может обойти ограничение non-GKI?

Нет. Local LKM доступен только для поддерживаемых GKI-устройств.
