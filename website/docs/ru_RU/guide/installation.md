# Установка

ApexSU предназначен только для поддерживаемых Android GKI-устройств.

## Требования

- Версия ядра должна содержать `android`  
  Пример: `5.10.209-android12-9-00016-g7c6bbcca33e1`
- `boot.img`, совпадающий с текущей прошивкой/сборкой
- ApexSU Manager

## Устройства non-GKI

- Не поддерживаются.
- Установка блокируется.
- Local LKM не является обходом для non-GKI.

## LKM

- Repository LKM: рекомендуемый вариант для поддерживаемых GKI
- Local LKM: расширенный ручной вариант только для поддерживаемых GKI

## Предупреждение по безопасности

Модификация boot image может вызвать bootloop. Обязательно сделайте резервную копию важных данных.
