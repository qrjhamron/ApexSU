# FAQ

## ApexSU 支援哪些裝置？

ApexSU 僅支援受支援的 Android GKI 裝置。若核心版本不含 `android`，則視為 non-GKI，不支援安裝。

## non-GKI 裝置可以安裝嗎？

不可以。non-GKI 裝置安裝會被阻擋。

## Local LKM 能當作 non-GKI 相容性繞過嗎？

不能。Local LKM 僅適用於受支援的 GKI 裝置。
